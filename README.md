# 🌦️ Atmosly – Weather Forecast Website

Atmosly is a responsive weather forecast website that provides real-time weather information and a five-day forecast for cities around the world. It features dynamic backgrounds and weather-based visual effects that change according to current weather conditions.

## ✨ Features

- **Real-Time Weather:** View current temperature, weather conditions, humidity, wind speed, and other weather details.
- **5-Day Forecast:** Check upcoming weather conditions and temperature forecasts.
- **City Search:** Search for a city to view its weather information.
- **Dynamic Weather Backgrounds:** Background themes adapt to different weather conditions, including clear skies, clouds, rain, fog, and snow.
- **Weather Animations:** Animated visual effects enhance the experience based on weather conditions.
- **Day & Night Themes:** Visual styling adapts to daytime and nighttime conditions.
- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **Temperature-Based Styling:** Cold-weather themes provide a more immersive experience.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## ⚙️ Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Zainab-Mustafa14/Atomsly
   ```

2. Open the project folder:

   ```bash
   cd atmosly
   ```

3. Configure your OpenWeather API key in the JavaScript file according to your project setup.

4. Open `index.html` in your browser or run the project using the VS Code Live Server extension.

## 🔑 API Configuration

Atmosly uses the [OpenWeather API](https://openweathermap.org/api) to retrieve current weather data and forecast information.

To run the project locally, obtain an API key from OpenWeather and configure it in the appropriate location in the JavaScript code.

**Security note:** Avoid committing private API keys or other secrets to a public repository.

## 🎯 Project Goal

The goal of Atmosly is to combine useful weather information with an engaging visual experience through responsive layouts, dynamic backgrounds, and condition-based animations.
